# Gas Giant Textures

Textures for warm gas giants — Jupiter and Saturn-like bodies.

## Characteristics
- Banded atmosphere with storms
- Amber, orange, tan, and cream tones
- No solid surface
- Often have ring systems and many moons

## Adding Textures

Drop any equirectangular planet texture here and register it in `assets/data/planet_textures.ron`:

```ron
"gas_giant": [
    "textures/celestial/planets/gas_giant/your_texture.jpg",
    // ... existing entries
],
```
