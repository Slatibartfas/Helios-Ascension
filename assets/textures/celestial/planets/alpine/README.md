# Alpine Planet Textures

Textures for cold habitable worlds with mountain ranges, snowcaps, and frosty highlands.

## Characteristics
- Cold but still habitable climates
- Snow-covered ridges, rocky uplands, and thin vegetation bands
- Pale grey, white, blue-grey, and muted brown tones
- Typical procedural band: -20C to below -5C

## Runtime Category
- Manifest key: `alpine`
- Used for cold worlds inside the habitable temperature range

## Adding Textures

Drop any equirectangular planet texture here and register it in `assets/data/planet_textures.ron`:

```ron
"alpine": [
    "textures/celestial/planets/alpine/your_texture.jpg",
    // ... existing entries
],
```

## Recommended Sources
- NASA Earth Observatory textures and terrain references
- Solar System Scope (CC BY 4.0) - https://www.solarsystemscope.com/textures/
- Custom procedural or painted mountain-world textures
