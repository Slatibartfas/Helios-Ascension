# Savannah Planet Textures

Textures for warm grassland worlds with open plains, sparse tree cover, and sun-baked terrain.

## Characteristics
- Grasslands, scrublands, and semi-arid warm plains
- Golden brown, olive, dusty green, and tan tones
- Hotter end of the habitable range
- Typical procedural band: above 45C inside the habitable window

## Runtime Category
- Manifest key: `savannah`
- Used for warm habitable terrestrial worlds at the hot edge of the habitable band

## Adding Textures

Drop any equirectangular planet texture here and register it in `assets/data/planet_textures.ron`:

```ron
"savannah": [
    "textures/celestial/planets/savannah/your_texture.jpg",
    // ... existing entries
],
```
