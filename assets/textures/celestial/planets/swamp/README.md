# Swamp Planet Textures

Textures for wetland worlds dominated by marshes, bogs, deltas, and dark saturated terrain.

## Characteristics
- Marshes, wetlands, muddy basins, and shallow water networks
- Dark green, brown, black-green, and murky blue tones
- Humid lowlands with heavy moisture retention
- Typical procedural band: temperate habitable worlds selected by biome split

## Runtime Category
- Manifest key: `swamp`
- Used for wet, marsh-like habitable terrestrial worlds

## Adding Textures

Drop any equirectangular planet texture here and register it in `assets/data/planet_textures.ron`:

```ron
"swamp": [
    "textures/celestial/planets/swamp/your_texture.jpg",
    // ... existing entries
],
```
