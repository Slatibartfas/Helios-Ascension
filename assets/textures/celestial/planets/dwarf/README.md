# Dwarf Planet Textures

Textures for dwarf planets and Kuiper Belt Objects — Pluto, Eris, Makemake-like bodies.

## Characteristics
- Small, often icy bodies in outer system regions
- Reddish tholins, bright nitrogen ice, or grey rock
- Wide variety from bright Eris-like to dark reddish Sedna-like

## Adding Textures

Drop any equirectangular planet texture here and register it in `assets/data/planet_textures.ron`:

```ron
"dwarf": [
    "textures/celestial/planets/dwarf/your_texture.jpg",
    // ... existing entries
],
```
