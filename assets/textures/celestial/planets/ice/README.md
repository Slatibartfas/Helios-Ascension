# Ice Planet Textures

Textures for deeply frozen worlds — Pluto-like bodies locked in extreme cold.

## Characteristics
- Solid ice and frozen gas surfaces
- White, pale blue, and grey tones
- Nitrogen/methane ice fields
- Temperatures: below –100°C

## Adding Textures

Drop any equirectangular planet texture here and register it in `assets/data/planet_textures.ron`:

```ron
"ice": [
    "textures/celestial/planets/ice/your_texture.jpg",
    // ... existing entries
],
```
